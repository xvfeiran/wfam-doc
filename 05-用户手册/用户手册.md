## 第一章 系统概述

### 1.1 系统简介

RBCC WFAM（Warranty Field Analysis Management）售后件管理系统用于管理退货单和售后件的全生命周期。核心业务流程为：

**退货登记 → 提交退货单 → 添加退件信息 → 结束录入（自动创建分析单）→ 抽样 → 精分析 → 审批 → WorkON 报废**

### 1.2 角色说明

系统通过博世 IDM 统一分配角色，共 6 个角色：

| 角色名称 | 简称 | 核心权限 |
|---------|------|---------|
| W_RBCC_AEP_WFAM_Customer_Quality | 客户质量工程师 | 查看退货单、退件信息、统计报表 |
| W_RBCC_AEP_WFAM_Analyst | 分析员 | 新建退货单/退件信息、精分析报告、抽样、报废 |
| W_RBCC_AEP_WFAM_QMC_Leader | 分析主管 | 全部权限 + 审批 + 数据校订 |
| W_RBCC_AEP_WFAM_QMC_Manager | QMC 经理 | 查看全部数据、统计报表 |
| R_RBCC_AEP_WFAM_Visitor | 访客 | 仅查看工作台和统计报表 |
| W_RBCC_AEP_WFAM_SystemAdmin | 系统管理员 | 全部权限 + 配置管理 |

### 1.3 浏览器要求

- Chrome 90+ / Edge 90+ / Firefox 88+
- 推荐分辨率：1920×1080

### 4.2 新建退货单

#### 操作步骤

1. 在退货单列表页点击「**新建**」按钮
2. 页面跳转到新建退货单表单
3. 填写以下字段：

**基本信息区域：**

| 字段名 | 输入方式 | 必填 | 提示文字/说明 |
|--------|---------|:---:|-------------|
| 客户 | 下拉选择 | ✅ | 请选择客户 |
| 收件日期 | 日期选择器 | ✅ | 请选择收件日期（不能选未来日期） |
| 投诉日期 | 日期选择器 | ✅ | 请选择投诉日期。**注意**：退回方式选「快递」时，投诉日期自动与收件日期保持一致，不可单独修改 |
| 退回方式 | 单选按钮 | ✅ | 快递 / 自提 / 其他 |
| 快递单号 | 文本输入 | 条件 | 退回方式选「快递」时必填，提示「请输入快递单号」，最长 50 字符 |
| 退回数量 | 数字输入 | ✅ | 请输入退回数量（1 ~ 9999） |
| 投诉类型 | 下拉选择 | ✅ | 请选择投诉类型（BA 代码列表，如 BA40 = field product） |
| 其他信息 | 多行文本 | ❌ | 最长 500 字 |

4. 填写完成后，页面底部有 3 个按钮：

| 按钮 | 说明 |
|------|------|
| **取消** | 放弃编辑，返回列表页 |
| **暂存** | 保存为草稿，状态 = `draft`，不生成退货单号。提示「已暂存」 |
| **提交** | 弹出确认提示「提交后无法修改，请确认！」，确认后生成退货单号（如 `26QMC0001`），状态 = `submitted`。提示「提交成功」 |

> **投诉类型标签**：选择 BA40 或 BA41 时，字段旁会显示蓝色「售后件」标签；选择其他 BA 代码时，显示橙色「0km」标签。

#### 操作按钮

| 按钮 | 显示条件 | 说明 |
|------|---------|------|

### 4.4 删除退货单

1. 在列表页勾选要删除的退货单
2. 点击「**删除**」按钮
3. 系统检查关联退件信息：
   - **无关联退件信息**：弹出确认框「确定删除选中的退货单？」→ 确认后删除
   - **有关联退件信息**：弹出警告框「无法删除」，列出有关联退件信息的退货单，提示「请先删除所有退件信息后再删除退货单」

### 4.5 报废摘要

当退货单状态为 `scrapped` 时，详情页显示报废摘要，格式为「{已报废数}/{总数} 分析单已报废」。

#### OCR 拍照识别

在车辆信息区域上方有 OCR 识别按钮栏：

| 按钮 | 说明 |
|------|------|
| **拍照** | 调用设备摄像头拍照 |
| **上传** | 从本地选择图片上传 |
| **停止识别** | 中断正在进行的识别 |
| **重新拍照** | 重新拍照识别 |

**OCR 操作步骤：**

1. 点击「**拍照**」或「**上传**」按钮
2. 系统上传图片并显示「**识别中...**」
3. 等待期间显示提示「已等待 {seconds}s，请耐心等待」
4. 识别完成后：
   - **成功**：弹出 OCR 预览窗口，左侧显示图片（支持滚轮缩放、拖动），右侧列出识别到的字段
   - **失败**：提示「OCR 识别失败，请手动填写相关字段」

5. 在预览窗口中可修改识别结果，点击「**确认应用**」同步到表单
6. 也可点击「**全部应用**」一键应用所有识别结果

> **重要**：OCR 识别中仅允许「暂存」，识别完成后方可「提交」。

- 未抽样（灰色标签）

### 6.4 抽样操作

**前提条件**：分析单状态为 `pending_sampling`

#### 操作步骤

1. 在分析单详情页点击「**抽样**」按钮
2. 弹出「**抽样管理**」弹窗
3. 选择抽样方式（三种）：

**方式一：标准抽样**
- 设置抽样比例（滑块或输入框）
- 设置抽样数量（与比例联动）
- 点击「**随机抽样**」按钮，系统自动随机选取指定数量的退件信息
- 提示「已随机抽取 {count} 个退件信息」

**方式二：指定抽样**
- 在穿梭框中搜索退件信息（提示「搜索零件号/零件码」）
- 手动勾选要抽样的退件信息
- 也可以通过「**手动抽样**」按钮逐个添加

**方式三：不抽样**
- 选择「**不抽样**」选项
- 弹出警告：「选择不抽样后，退货单将直接进入待报废流程，请确认！」
- 点击「**确认不抽样**」

4. 选择完成后点击「**确认抽样**」
5. 系统提示「抽样完成，共抽取 {count} 个退件信息」
6. 被选中的退件信息状态变为 `in_detailed_analysis`
7. 分析单状态变为 `in_detailed_analysis`

#### 重新抽样

- 已完成抽样的分析单，QMC Leader 可切换至编辑模式
- 点击「**重新抽样**」按钮
- 弹出警告：「重新抽样将重置所有退件信息状态，原有抽样结果将被覆盖，请谨慎操作！」
- 确认后可重新选择抽样方案

#### 查看抽样结果

- 已完成抽样的分析单，点击「**查看抽样结果**」按钮
- 弹出「**抽样结果查看**」弹窗，以只读模式展示抽样结果

### 6.5 报废操作

**前提条件**：分析单状态为 `analysis_completed`（精分析/审批完成），且所有售后件满足「未抽样」或「已抽样且精分析审批完成」条件。

#### 操作步骤

1. 在分析单详情页点击「**报废**」按钮
2. 系统执行前置校验：
   - 如果分析单处于待抽样状态，提示「该分析单处于待抽样状态，请先完成抽样后再进行报废操作」
   - 如果有抽样件未完成精分析，提示「有 {count} 个抽样件尚未完成精分析，请等待所有抽样件精分析完成后再进行报废操作」
3. 校验通过后弹出「**报废处理**」弹窗，显示：
   - 提示：「本系统仅用于标记报废状态，实际报废操作需在 WorkON 系统中完成。请复制以下信息到 WorkON 系统进行报废申请。」
   - 退货单号
   - 报废数量
   - 当前状态
   - **WorkON 报废链接**（蓝色链接，提示「点击进入 WorkON 报废页面」）
   - 备注（可选输入，提示「请输入备注信息（可选）」）
4. 点击「**确认标记**」按钮
5. 所有关联退件信息状态变为 `scrap_in_progress`
6. 分析单状态变为 `workon_scrap_in_progress`
7. 提示「报废申请已提交」

#### 确认 WorkON 完成

1. 在 WorkON 系统中完成报废操作后，返回分析单详情页
2. 点击「**确认 WorkOn 完成**」按钮
3. 弹出确认弹窗，要求填写：
   - **WorkON 报废单号**（必填，提示「请输入 WorkON 报废单号」）
4. 确认后：
   - 分析单状态变为 `workon_scrapped`（终态）
   - 所有关联退件信息状态变为 `scrapped`

### 附录 D：常见问题

**Q1：如何区分草稿和已提交的退件信息？**

草稿状态的退件信息没有编号，列表中编号显示为灰色且不可点击。提交后系统自动生成编号（如 `RBCABS-WSA-0001`），编号显示为蓝色链接。

**Q2：为什么无法添加退件信息？**

只有在退货单状态为「草稿」或「信息登记/已完成」时才能添加。状态为「退件登记/已完成」时不可添加，页面会显示「已关闭」提示。

**Q3：为什么无法抽样？**

- 仅 BA40 类型的退货单可触发抽样
- 抽样操作在分析单中进行，需要分析单状态为「待抽样」
- 0km 退货单不能抽样，提示「0km 退货单不能抽样，只能走报废流程」

**Q4：精分析报告模板如何匹配？**

系统根据退件信息的产品平台和失效类型自动匹配模板，优先级：精确匹配 > 平台匹配 > 默认模板。

**Q5：如何修改已提交的数据？**

仅分析主管（QMC Leader）和系统管理员拥有「数据校订」权限，可修改已提交的表单。

**Q6：为什么收不到邮件通知？**

请确认：① 系统管理员已配置邮件服务器 ② 用户信息中包含邮箱 ③ 联系管理员检查通知日志。

**Q7：OCR 识别失败怎么办？**

系统会提示「OCR 识别失败，请手动填写相关字段」，直接手动填写即可。也可以点击「重新识别」重试。

**Q8：提交时提示「请检查表单填写」？**

检查所有必填字段是否已填写（标红色星号 * 的字段），纠正后重新提交。
