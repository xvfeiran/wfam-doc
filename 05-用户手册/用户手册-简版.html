RBCC WFAM 售后件管理系统 — 简明使用手册

本手册为快速上手版，仅覆盖核心操作。完整字段与细节请见《用户手册.md》。
文档日期：2026-07-28

一、系统是干什么的

管理客户退货件的全生命周期，主线流程：

退货登记 → 提交退货单 → 录入退件信息 → 结束录入（自动建分析单）
        → 抽样 → 精分析 → 审批 → WorkON 报废

登录：本系统嵌入博世 Portal，在 Portal 登录后从应用中心进入，无需单独登录。
浏览器：Chrome / Edge / Firefox 最新版，推荐 1920×1080。

二、角色

共 6 个角色，由博世 IDM 分配：

角色 能做什么
客户质量工程师 查看退货单、退件、报表
分析员 Analyst 新建单据、做精分析、抽样、报废（仅自己的数据）
分析主管 QMC Leader 全部权限 + 审批 + 数据校订
QMC 经理 查看全部数据、报表
访客 Visitor 只看工作台和报表
系统管理员 全部权限 + 配置管理

三、工作台（首页）

进入系统默认看到数据看板：

  • 4 个统计卡片：退货单总量、退件信息总量、任务待处理、分析完成率。点卡片可跳转对应列表。
  • 数量趋势图：退货单 / 退件信息两条折线，可切换 日/周/月/年。
  • 任务中心：列出各类待办（待录入、待精分析、预警、超期、待审批、待报废确认），点击自动带筛选跳转。
  • 快捷入口：快速登记退货单、新增退件、统计报表、WorkON、Lessons Learned、帮助 FAQ。

四、退货单管理

列表页

  • 顶部按 退货单号 / 客户 / 收件日期 / 状态 筛选。
  • 按钮：新建、导出（Excel）、编辑（选中 1 条）、删除（选中后确认）。
  • 点退货单号（蓝色）进详情。

新建退货单

必填：客户、收件日期、投诉日期、退回方式、退回数量、投诉类型。

  • 退回方式选「快递」时，投诉日期自动等于收件日期，且必须填快递单号。
  • 投诉类型选 BA40/BA41 → 显示蓝色「售后件」标签（可走抽样）；其他 BA → 橙色「0km」标签。
  • 底部三按钮：取消 / 暂存（存为草稿，不生成单号）/ 提交（生成单号如 26QMC0001，提交后不可改）。

详情页

  • 看基本信息、统计信息、状态步骤条、退件信息列表。
  • 结束录入：已提交且有至少 1 条退件信息时可点。确认后状态变「退件登记/已完成」，并自动按分析师分组创建分析单。结束后不能再增删零件。

删除

有关联退件信息时不能删，需先删退件。

五、退件信息管理

新建退件信息

三个区域：

  1. 基础信息：关联退货单（仅草稿/已提交的可选）、零件号（输入后自动带出 BU 和产品平台）、退件编号（4 位数字，页面会给建议序号）。
  2. 客诉信息：仅「售后件」（BA40/BA41）显示；0km 隐藏。含投诉类型、客户失效类型、分析师等。
  3. 车辆信息：仅售后件显示。可用 OCR 拍照/上传 自动识别 VIN、里程等字段，识别失败就手填。
  • 底部：取消 / 暂存（无编号）/ 提交（生成编号）。
  • 编号规则：{BU代码}-{平台代码}-{4位序号}，如 RBCABS-WSA-0001；BU 为空时用 BLANK 占位。
  • 照片：支持 jpg/png/jpeg，单张 ≤10MB，最多 20 张。

详情页

  • 右侧状态步骤条 + 精分析报告卡片（有则显示，可查看/导出）。
  • 精分析完成（状态 ≥ analysis_completed）后，上方可录入 QC No.。
  • 状态为「精分析/进行中」时显示精分析按钮，点进去填报告。

六、分析单管理

分析单以「退货单 × 分析师」为粒度，结束录入时自动生成。分析员只能看自己的。

抽样（前提：分析单为「待抽样」）

点抽样按钮，三种方式：

  • 标准抽样：设比例/数量 → 随机抽取。
  • 指定抽样：穿梭框手动勾选。
  • 不抽样：直接进报废流程（会警告确认）。

0km 退货单不能抽样，直接走报废。
QMC Leader 可对已抽样单重新抽样（会重置结果）。

报废（前提：精分析审批完成）

  1. 点报废 → 校验通过后弹出报废处理窗，显示退货单号、数量、WorkON 链接。
  2. 点确认标记 → 状态变「WorkOn 报废中」。
  3. 去 WorkON 系统完成实际报废后，回来点确认 WorkOn 完成，填 WorkON 报废单号 → 状态终态「已报废」。

七、精分析报告

从退件详情页点精分析进入。表单顶部选责任判定（B 博世/C 客户/S 供应商/O 其他）和模板（按平台+失效类型自动匹配）。

底部按钮：

  • 暂存草稿
  • 提交审批 → 自动路由给 QMC Leader
  • 下载报告（提交后可导出 Excel）

八、审批（仅 QMC Leader / 系统管理员）

两个 Tab：

  • 我的申请：自己提交的报告，待审批状态可撤回。
  • 待我审批：等审批的报告，可通过或驳回（驳回必填原因）。

通过 → 退件状态推进；驳回 → 退件回退到精分析中，分析员收到通知。

九、其他模块（简述）

  • 统计报表：分析报表 / 质量报表。按客户、BU、平台、失效模式等维度出图，可导出 Excel。全部角色只读。
  • 导入：批量导入退货单 / 退件信息（Excel 或文件夹路径），后台逐行处理，有成功/失败明细，可撤销本次导入。
  • 配置（仅系统管理员）：精分析模板、数据字典（客户/零件号）、邮件服务器、SMB 存储。

附录 B：常见问题

  • 草稿和已提交怎么区分？ 草稿无编号、灰色不可点；提交后生成编号、变蓝色链接。
  • 加不了退件信息？ 退货单必须处于「草稿」或「已提交」；「退件登记/已完成」会显示「已关闭」。
  • 不能抽样？ 只有售后件（BA40/BA41）能抽样，且分析单需为「待抽样」；0km 直接报废。
  • 改不了已提交数据？ 只有 QMC Leader / 系统管理员有「数据校订」权限。
  • OCR 失败？ 提示后直接手填，或点重新识别重试。
