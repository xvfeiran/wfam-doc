## 一、精分析报告模板概述

精分析报告使用 Excel 模板（`.xlsx`）定义报告的结构和字段。系统通过扫描模板中的**占位符**自动生成前端表单，并在导出报告时将占位符替换为实际数据。

### 占位符格式

```
[[类型:字段名:中文标签:英文标签:是否必填:选项列表]]
```

| 部分 | 说明 | 示例 |
|------|------|------|
| 类型 | 字段输入类型 | `text`、`textarea`、`select`、`date`、`number` |
| 字段名 | 英文标识，用于数据存储和匹配 | `noiseType` |
| 中文标签 | 前端表单显示的中文名称 | `噪音类型` |
| 英文标签 | 前端表单显示的英文名称 | `Noise Type` |
| 是否必填 | `true` 或 `false` | `true` |
| 选项列表 | `select` 类型的可选项，逗号分隔 | `选项1,选项2,选项3` |

### 示例

```
[[text:noiseType:噪音类型:Noise Type:true:]]
[[textarea:failureDescription:故障描述:Failure Description:false:]]
[[select:primaryFailureCause:主要故障原因:Primary Failure Cause:true:选项1,选项2,选项3]]
[[date:analysisDate:分析日期:Analysis Date:false:]]
[[number:testCount:测试次数:Test Count:false:]]
```

## 二、模板上传流程

1. 进入系统 **设置 → 模板管理** 页面
2. 点击 **上传模板**
3. 填写模板名称、选择产品平台和失效类型
4. 上传包含占位符的 Excel 文件（`.xlsx`）
5. 系统自动解析占位符并生成字段定义

## 三、系统保留字段

以下字段由系统自动管理，**不属于模板动态字段**，但在精分析弹窗中以固定控件形式展示：

### 3.1 责任判定（Responsibility）

| 属性 | 值 |
|------|------|
| 字段名 | `responsibility` |
| 可选值 | `B`（Bosch）、`C`（Customer）、`S`（Supplier）、`O`（Open） |
| 存储位置 | 数据库列 + 报告内容 JSON（冗余） |
| 用途 | 标记精分析的责任归属 |

#### Excel 模板中如何使用

如果需要在导出的 Excel 报告中显示责任判定值，请在模板对应单元格中添加以下占位符：

```
[[select:responsibility:责任判定:Responsibility:true:B,C,S,O]]
```

导出时系统会自动将该占位符替换为实际选择的责任判定值（如 `B`、`C`、`S` 或 `O`）。

> **注意：**
> - 如果模板中不包含此占位符，责任判定值仍会正常保存到数据库，但不会出现在导出的 Excel 中。
> - 责任判定的输入控件固定显示在精分析弹窗顶部的匹配条件区域，**不会被模板表单重复渲染**。即使模板中包含 `responsibility` 占位符，前端也会自动跳过该字段的表单渲染，仅用于 Excel 导出时的占位替换。

## 四、完整模板示例

以下是一个精分析报告模板的占位符布局参考：

```
| 零件编号: [[text:partNumber:零件编号:Part Number:true:]]      | 产品平台: [[text:platform:产品平台:Platform:true:]] |
| 失效类型: [[text:failureType:失效类型:Failure Type:true:]]    | 责任判定: [[select:responsibility:责任判定:Responsibility:true:B,C,S,O]] |
| 失效描述: [[textarea:failureDesc:失效描述:Failure Description:true:]] |
| 根本原因: [[textarea:rootCause:根本原因:Root Cause:true:]]       |
| 分析结论: [[textarea:conclusion:分析结论:Conclusion:true:]]       |
```

---

## 五、注意事项

1. **占位符必须写在单个单元格内**，不能跨单元格拆分
2. **字段名（name）不能重复**，同一模板内每个占位符的字段名必须唯一
3. **系统保留字段**（如 `responsibility`）可出现在模板中，但前端弹窗中由系统固定渲染，不受模板定义影响
4. 占位符中的逗号、冒号、方括号为语法字符，标签文本中请避免使用这些字符
