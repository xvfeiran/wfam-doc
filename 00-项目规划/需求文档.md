- **项目名称**：RBCC WFAM 售后件管理系统
- **文档版本**：v1.0
- **创建日期**：2026-01-30
- **原型类型**：交互原型

---

## 一、项目概述

### 1.1 项目背景
RBCC WFAM售后件管理系统是一个用于管理退货单、售后件的全流程系统，涵盖从退货登记、抽样管理、精分析报告到报废申请的完整业务流程。

### 1.2 项目目标
- 提供直观的Web界面进行退货单和售后件管理
- 实现售后件全流程可视化追溯
- 支持OCR图像识别提高数据录入效率
- 提供数据统计和分析功能，辅助质量改进决策

### 1.3 项目范围
本次开发为**交互原型**，包含以下4个核心模块：
1. 工作台（仪表盘）
2. 退货单管理
3. 售后件管理
4. 统计报表

### 2.2 抽样管理

#### 2.2.1 抽样确认
**抽样方式**：
1. **标准抽样**：手动选择（不实现自动计算逻辑）
2. **指定抽样**：手动选择特定样本
3. **不抽样**：跳过抽样流程

#### 2.2.2 样本选取与编号
**流程**：
1. 用户从退货单关联的售后件列表中选择样本
2. 系统自动分配样本编号
3. 样本编号规则：`BU + 产品平台 + 序号`（如：BU1-PLT1-0001）
4. 记录抽样信息（抽样人、抽样时间、抽样数量）

#### 2.2.3 编辑抽样结果
**功能**：
- 修改已选样本
- 调整样本编号
- 重新选择样本

#### 2.2.4 抽样结果确认
**功能**：
- 确认样本的代表性
- 确认后同步更新样本状态为"待精分析"
- 不可再次修改（除非撤销）

**UI设计**：
- 弹窗形式
- 左侧：售后件列表（可勾选）
- 右侧：已选样本列表（显示编号、可删除）
- 底部：取消、暂存、确认按钮

#### 3.2.3 信息卡OCR扫描功能

**功能设计**：
1. **拍照识别按钮**：点击后触发文件上传或摄像头
2. **停止识别按钮**：中断识别过程
3. **全部应用按钮**：一键应用所有识别结果

**识别字段**：
- 汽车生产日期
- 汽车购买日期
- 汽车失效（维修）日期
- 汽车VIN码/底盘号/车架号
- 汽车行驶里程
- 客户失效描述

**UI交互流程**：
1. 用户点击"拍照识别"
2. 上传图片后，对应字段旁边显示loading图标
3. 识别过程中，用户仍可手动填写字段
4. 识别完成后，在字段旁边显示识别结果卡片
5. 识别结果卡片内容：
   - 识别值（文本）
   - "应用"按钮（单个字段）
   - 置信度指示（可选）
6. 用户可以点击"全部应用"或单个"应用"按钮
7. 应用后，识别结果填入对应输入框
8. 用户可以继续手动修改

**UI布局示例**：
```
[输入框] [识别中...] 或 [识别结果: XXXX] [应用]
```

#### 3.2.4 照片上传区
**功能**：

- 拖拽上传或点击上传

## 三、非功能需求

### 3.1 性能要求
- 页面加载时间 < 2秒
- 列表分页加载，单页最多100条
- 图片上传支持压缩
- 大列表使用虚拟滚动

### 3.2 兼容性要求
- 浏览器：Chrome 90+, Edge 90+, Firefox 88+
- 分辨率：最低支持 1366×768，推荐 1920×1080

### 3.3 用户体验要求
- 响应式设计（桌面优先）
- 加载状态提示（Spinner/Skeleton）
- 操作反馈（Toast提示）
- 表单验证实时反馈
- 二次确认（删除、提交等关键操作）

### 3.4 安全要求
- 文件上传类型校验
- 文件大小限制
- XSS防护（输入过滤）
- 敏感操作日志记录

## 五、UI/UX设计要求

### 5.1 设计风格
- 简洁、专业的企业级应用风格
- 主色调：Bosch蓝（或根据企业VI）
- 辅助色：灰色系
- 强调色：红色（警告）、橙色（提醒）、绿色（成功）

### 5.2 布局
- **顶部导航栏**：Logo + 导航菜单 + 用户信息
- **左侧边栏**：功能模块导航（可折叠）
- **主内容区**：面包屑 + 页面标题 + 内容区域
- **底部**：版权信息（可选）

### 5.3 组件规范
- **按钮**：主按钮、次按钮、文本按钮、图标按钮
- **表单**：
  - 标签在输入框上方
  - 必填项标*
  - 错误提示在输入框下方
  - 帮助文本用浅色
- **表格**：
  - 斑马纹
  - 悬停高亮
  - 固定表头（长列表）
- **弹窗**：
  - 遮罩层
  - 居中显示
  - ESC关闭

### 5.4 状态反馈
- **加载中**：Spinner或骨架屏
- **成功**：绿色Toast，2秒自动消失
- **错误**：红色Toast，需手动关闭
- **警告**：橙色Toast，3秒自动消失
