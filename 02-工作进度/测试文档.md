**退货单状态列表**：
| 状态编码 | 状态名称 | 中文标签 | 颜色标识 | 说明 |

| `draft` | Draft | 草稿 | 灰色 | 新建未提交的退货单 |
| `in_initial_analysis` | In Initial Analysis | 初分析中 | 蓝色 | 已提交，等待初分析 |
| `in_detailed_analysis` | In Detailed Analysis | 精分析中 | 蓝色 | 抽样完成，等待精分析 |

| `scrapped` | Scrapped | 已报废 | 绿色 | 报废完成 |

**状态流转规则**：
```
draft → in_initial_analysis → in_detailed_analysis → scrap_in_progress → scrapped
```

## 十、缺陷跟踪

### 缺陷状态定义

| 状态 | 说明 |
|-----|------|
| 🐛 新发现 | 新发现的缺陷 |
| 🔍 处理中 | 正在修复的缺陷 |
| ✅ 已修复 | 开发修复完成 |
| 🧪 待验证 | 修复完成，等待测试验证 |
| ✅ 已验证 | 测试通过，缺陷关闭 |
| ❌ 重复问题 | 重复提交或非缺陷 |
| ⏸️ 暂不修复 | 优先级低，暂不修复 |

### 缺陷优先级

| 优先级 | 说明 | 示例 |
|-------|------|------|
| P0 - 阻塞 | 阻碍核心功能，必须立即修复 | 无法登录、数据丢失 |
| P1 - 严重 | 严重影响使用，必须尽快修复 | 功能无法使用、数据错误 |
| P2 - 一般 | 影响部分功能，应尽快修复 | 界面显示问题、功能受限 |
| P3 - 较低 | 轻微影响，可以延后处理 | 界面优化、文案错误 |
| P4 - 建议 | 改进建议，可选择性处理 | 体验优化 |
